# Alexandria

This is a web app for tracking the manga and shows you're reading or watching: the title, the site, the status of the manga or show, and the chapter or episode you stopped at.

## Features
- Add a manga or show with its site, status and current chapter or episode
- Update progress with a +1 button or by typing a specific number
- Delete entries
- Input validation on the server
- Entries are saved to a JSON file, so they persist between sessions

## Built with
Python, Flask, HTML, CSS, Jinja templates.
Built while learning Flask, with help from AI tools for guidance and debugging

## How to run
1. Clone the repo
2. Create and activate a virtual environment:
   `python3 -m venv venv` then `source venv/bin/activate`
3. Install Flask: `pip install flask`
4. Run: `flask run`
5. Open http://127.0.0.1:5000
